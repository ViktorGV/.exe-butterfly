# nuke

Atom bomb animation: a blinding flash, a fireball rising on a stem and a mushroom cloud that spreads and fades.
The server drops the bomb once per race when pushes plus shotgun and rocket hits reach `NUKE.THRESHOLD`
(see `apps/server/src/butterfly`); everyone who pushed or shot anyone and is still racing goes back one checkpoint.

Demo: `/demos/nuke.html`.
